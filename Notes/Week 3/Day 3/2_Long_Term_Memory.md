Exactly. Once you move beyond **conversation memory**, **long-term memory** is commonly divided into these three categories:

```text
Long-Term Memory
│
├── 1. Episodic Memory
├── 2. Semantic Memory
└── 3. Procedural Memory
```

### 1. Episodic Memory (Experiences)

Stores **events or interactions** that happened.

**Example**

```text
User:
Yesterday I booked a flight to Dubai.

AI:
I'll remember that you booked a flight yesterday.
```

Later:

```text
User:
What did I do yesterday?

AI:
You booked a flight to Dubai.
```

Think of it as:

> 📖 Your diary or journal.

---

### 2. Semantic Memory (Facts)

Stores **facts about the user**, independent of when they were learned.

**Example**

```text
Name:
Imran

University:
UCP

Favorite Language:
Python

Dream:
Build Jarvis
```

Later:

```text
User:
What's my favorite language?

AI:
Python.
```

Think of it as:

> 📚 Your personal profile or knowledge base.

This is exactly what ChatGPT's Memory feature mainly does.

---

### 3. Procedural Memory (How to Do Things)

Stores **instructions, preferences, or procedures** about how the AI should behave.

Examples:

```text
Always answer in simple English.

Use bullet points.

Call me Bro.

Never use emojis in code.

Explain concepts first, then code.
```

Or for Jarvis:

```text
When checking university updates:

1. Login
2. Check portal
3. Notify through WhatsApp
4. Save assignment
```

Think of it as:

> ⚙️ Rules, habits, and operating instructions.

---
