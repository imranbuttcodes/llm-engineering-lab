# LLM Engineering Lab

A hands-on engineering lab for building LLM applications, RAG systems, AI agents, structured outputs, evals, and deployment workflows.

## Goal

This repository tracks my Summer 2026 roadmap for becoming an AI/LLM application builder through practical, project-driven work.

## Focus Areas

* LLM fundamentals and prompting
* Structured outputs and tool calling
* Embeddings and vector databases
* Retrieval-Augmented Generation (RAG)
* LangChain and LangGraph workflows
* AI agents with tool use
* Evaluation harnesses and reliability testing
* FastAPI / Streamlit deployment workflows

## Roadmap Structure

* **Foundations** — small tools, RAG basics, LangGraph practice
* **Projects** — real build projects such as a RAG chatbot and an AI agent
* **Evals** — test cases, retrieval checks, and agent evaluation
* **Notes** — learning notes, observations, and debugging lessons
